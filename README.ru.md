# SimplyFive Light — генератор LOD для Blender в один клик

Аддон для Blender, который генерирует набор LOD-мешей (Level of Detail) из
активного объекта. Для каждого меша можно создать до 5 упрощённых версий,
каждая со своим процентом треугольников и режимом качества — в один клик.

**Light** — бесплатная версия. Она самодостаточна и полезна сама по себе;
отдельная версия **Pro** добавляет тонкую настройку каждого уровня и
дополнительные опции переноса (см. раздел *Версия Pro* ниже).

Автор: zloy_pingvin
Требуемая версия Blender: 4.2.0+ (проверено на 4.2, 4.5.11 LTS, 5.0 и 5.2 LTS)

## Возможности (Light)

- До 5 LOD-уровней на объект, каждый со своим процентом треугольников.
- 5 режимов качества в один клик на уровень: **Careful**, **Standard**,
  **Aggressive**, **Very Aggressive** и **Very Aggressive Alternative** — чем
  дальше уровень, тем агрессивнее режим. Два режима Very Aggressive отличаются
  одним: Alternative добавляет проход Decimate до точного процента, что одним
  моделям идёт, а другим нет.
- **Recalculate + Smooth** на режимах Very Aggressive: строит нормали по
  упрощённой геометрии, потому что на очень низком поликаунте нормали исходника
  ей уже не соответствуют.
- Атрибутно-осознанное упрощение: сохраняет UV и нормали, чтобы швы и жёсткие
  рёбра не разрушались.
- Вершинные цвета переносятся на LOD и, по желанию, используются как **карта
  важности** по вершинам — закрасьте области, где нужно сохранить больше
  деталей, источником может быть слой цвета или группа вершин. Один общий
  переключатель на все уровни.
- **Проверки источника** (Preferences), которые ловят две вещи, молча
  останавливающие упрощение насмерть: никогда не развёрнутую UV-карту и
  поверхность, продублированную под второй материал. Обе показываются до
  генерации, и обе можно обойти автоматически.
- **Optimize for GPU**: переупорядочивает треугольники и вершины так, как их
  читает видеокарта, не меняя геометрию.
- Перенос нескольких UV-каналов — все каналы источника, а не только активный.
- Поддержка нескольких материалов, включая материалы на линкованных
  дубликатах/инстансах или полученные через Geometry Nodes.
- Merge by Distance на результате для чистого сваривания швов.
- Настраиваемый суффикс имени LOD (Preferences), по умолчанию `_lod_`.
- Предпросмотр LOD прямо во вьюпорте, а также режим обзора **Line Up
  LODs** — выстраивает все уровни в ряд для сравнения бок о бок.
- Проверка обновлений раз в сутки, выключается одним переключателем — с
  выключенной аддон вообще не обращается к сети.
- Русский интерфейс.

## Версия Pro https://zloy-pingvin.github.io/SimplyFive-Light/

Pro включает всё из Light и добавляет:

- Полную тонкую настройку каждого параметра упрощения для каждого уровня. Light
  показывает тот же блок неактивным, так что видно, с чем генерируется уровень.
- Цепочку LOD — упрощение каждого уровня из предыдущего для более чистых
  дальних LOD.
- **Жёсткую блокировку** по цвету вершин: гарантия, что важные области не
  будут упрощены.
- Маску важности на каждый уровень отдельно: близкий может закрепить немного,
  дальний — всё.
- Пересчёт нормалей + Auto Smooth по углу, а также режим Sharp Loops,
  достраивающий разорванные конструктивные лупы, для очень низкополигональных
  уровней.
- **Accurate Vertex Colors**: смешивание цвета вдоль схлопывания, чтобы
  закрашенный градиент не выходил ступеньками.
- **Protect Material Borders** отдельным переключателем от UV-швов.
- **Limit Prune**: не даёт обрезке удалять детали целиком.
- Дополнительный ультра-агрессивный режим, игнорирующий топологию, воксельный
  ремешер и проход «регуляризации» для более равномерных треугольников.
- Сохранение и загрузку полной конфигурации в виде именованных пресетов, плюс
  редактируемые пресеты режимов.


## Установка

1. Blender → Edit → Preferences → Add-ons.
2. Меню в правом верхнем углу → «Install from Disk…» → выбрать архив
   SimplyFive Light.
3. Включить галочку напротив аддона «SimplyFive Light».

Библиотека упрощения уже встроена в аддон — ничего дополнительно собирать не
нужно.

## Быстрый старт

1. Выделите меш-объект во вьюпорте.
2. Откройте боковую панель (N) → вкладка «LODS».
3. Задайте «Number of LODs» (обычно достаточно 3–4).
4. Для каждого уровня выберите режим (Careful / Standard / Aggressive /
   Very Aggressive) — чем дальше уровень от «0», тем агрессивнее должен быть
   режим.
5. При желании поправьте процент треугольников (%) для каждого уровня.
6. Нажмите «Generate LODs».

Исходный объект будет переименован в «имя_lod_0», рядом появятся
«имя_lod_1», «имя_lod_2» и так далее — по одному на каждый уровень (суффикс
`_lod_` можно поменять в Preferences). Слайдер «LOD Preview (distance)»
позволяет посмотреть каждый уровень отдельно, а кнопка-значок рядом с ним
(«Line Up LODs») выстраивает все сгенерированные уровни в ряд для сравнения
бок о бок.

полная документация https://zloy-pingvin.github.io/SimplyFive-Light/docs.html
