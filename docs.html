SimplyFive — One-click LOD GeneratorSimplyFive — генератор LOD в один клик

A Blender add-on that generates a set of LOD meshes (Levels of Detail) from the active object, using the meshoptimizer library. For each mesh you can create up to 5 simplified versions with individual aggressiveness; simplification can take UV unwrapping, normals, vertex colors (as an importance map) and materials into account.Аддон для Blender, который генерирует набор LOD-мешей (Level of Detail) из активного объекта с помощью библиотеки meshoptimizer. Для каждого меша можно создать до 5 упрощённых версий с индивидуальной агрессивностью; упрощение может учитывать UV-развёртку, нормали, вершинные цвета (как карту важности) и материалы.

1.What the add-on doesЧто делает аддон

SimplyFive creates several simplified copies of your model in one click (LOD — Level of Detail): the farther an object is from the camera, the fewer polygons it needs. The add-on figures out on its own how to remove the “extra” triangles so that the silhouette, textures and shading suffer as little as possible.

SimplyFive создаёт несколько упрощённых копий модели в один клик (LOD — уровень детализации): чем дальше объект от камеры, тем меньше полигонов ему нужно. Аддон сам решает, как убрать «лишние» треугольники, чтобы силуэт, текстуры и затенение пострадали как можно меньше.

2.Installing the add-onУстановка аддона

  1. Open Blender → Edit → Preferences → Add-ons.Откройте Blender → Edit → Preferences → Add-ons.
  2. Open the drop-down at the top right and pick “Install from Disk…”, then select the SimplyFive archive.Откройте меню в правом верхнем углу, выберите «Install from Disk…» и укажите архив SimplyFive.
  3. Enable the checkbox next to the add-on in the list.Включите галочку напротив аддона в списке.

2.1 The meshoptimizer library2.1 Библиотека meshoptimizer

The add-on uses the third-party meshoptimizer library, which does the actual geometry simplification. It is already bundled inside the add-on — no extra steps are needed, the generation buttons work right after installation. You can open Preferences to confirm the library status reads ready.

Аддон использует стороннюю библиотеку meshoptimizer, которая выполняет само упрощение геометрии. Она уже встроена в аддон — ничего дополнительно делать не нужно, кнопки генерации работают сразу после установки. В Preferences можно убедиться, что статус библиотеки — ready (готова).

Pro Tip: Pro can also rebuild the library from source (e.g. to pull a newer meshoptimizer) with a button in Preferences — see Appendix A. Light always ships and loads the bundled library only.Совет: Pro также умеет пересобирать библиотеку из исходников (например, чтобы взять более свежий meshoptimizer) кнопкой в Preferences — см. Приложение A. Light всегда только загружает встроенную библиотеку.

4.Creating LODs in 5 stepsСоздание LOD в 5 шагов

  1. Select the model (best to work with final, finished geometry).Выделите модель (лучше работать с финальной геометрией).
  2. In “Number of LODs”, set how many levels you need (3–4 is usually enough).В поле «Number of LODs» задайте число уровней (обычно достаточно 3–4).
  3. For each level, pick a Mode from the dropdown: the farther the level is from “0”, the more aggressive the mode should be (see the table in section 5).Для каждого уровня выберите режим (Mode): чем дальше уровень от «0», тем агрессивнее режим (см. таблицу в разделе 5).
  4. Optionally adjust the triangle percentage (%) for each level.При желании поправьте процент треугольников (%) для каждого уровня.
  5. Click the big “Generate LODs” button at the bottom.Нажмите большую кнопку «Generate LODs» внизу.

After generation, new objects appear: your original is renamed to name_lod_0, and name_lod_1, name_lod_2, … appear next to it — one per level.

После генерации появятся новые объекты: исходный переименуется в name_lod_0, рядом появятся name_lod_1, name_lod_2, … — по одному на уровень.

Important:Важно: Running generation again for the same object deletes and recreates old LOD objects with the same names — previous versions are not kept.Повторный запуск генерации для того же объекта удаляет и пересоздаёт старые LOD-объекты с теми же именами — предыдущие версии не сохраняются.

Что лучше — зависит от модели, пробуйте оба на самых дальних уровнях.

Pro For finer control, expand “Details” under the mode — that’s where all the individual parameters live (section 7). On both Very Aggressive modes a Recalculate + Smooth checkbox appears under the mode. It throws the source normals away and builds new ones from the simplified geometry; the Crease Angle below it sets which edges stay hard (45° by default — lower keeps more edges crisp). Worth trying when a very low level shades as if dented — at that triangle count the source normals no longer describe the shape that is left. It is off by default and switching modes does not reset it.На обоих режимах Very Aggressive под режимом появляется галочка Recalculate + Smooth. Она отбрасывает нормали исходника и строит новые по упрощённой геометрии; Crease Angle под ней задаёт, какие рёбра остаются жёсткими (по умолчанию 45° — меньше значение, больше рёбер сохранит резкость). Стоит попробовать, когда очень низкий уровень затеняется как будто вмятинами — на таком поликаунте нормали исходника уже не описывают оставшуюся форму. По умолчанию выключена, смена режима её не сбрасывает.

6.1 Importance mask — keep chosen areas detailed6.1 Маска важности — сохранить детали в нужных зонах

Mark important areas (a face, a logo, a small detail) and the add-on treats them more carefully while simplifying unimportant ones (a back, a sole) more aggressively. The mask can come from a vertex color layer (paint white = important in Vertex Paint) or a vertex group (weight 1 = important in Weight Paint) — pick which with Importance Source.

Отметьте важные области (лицо, логотип, мелкая деталь) — аддон будет к ним бережнее, а неважные (спина, подошва) упростит агрессивнее. Маску можно взять из слоя вершинного цвета (белый = важно, в Vertex Paint) или из группы вершин (вес 1 = важно, в Weight Paint) — выбор в Importance Source.

Эти вершины помечаются для meshoptimizer как приоритетные, то есть схлопывать их действительно дорого. 7.The “Details” sectionРаздел «Details»

Light decides these parameters from the mode you picked, so there is nothing to edit here. The Details block shows them anyway, greyed out: the values your level is actually generated with, plus the controls Pro adds. Hovering a row explains what the parameter does. Which rows appear depends on the mode — exactly as in Pro, so Careful hides the two Protect rows because it does not use Permissive.

В Light эти параметры задаёт выбранный режим, поэтому править здесь нечего. Блок Details всё равно их показывает — неактивными: это настоящие значения, с которыми генерируется ваш уровень, плюс те регуляторы, которые добавляет Pro. При наведении на строку появляется описание параметра. Какие строки видны, зависит от режима — точно так же, как в Pro: на «Careful» двух строк Protect нет, потому что он не использует Permissive.

7.Fine-tuning each level — the “Details” sectionТонкая настройка каждого уровня — раздел «Details» Pro

The built-in modes are enough for most cases. But if something’s off — the model “breaks”, the texture drifts, or too many polygons remain — expand “Details” under that level’s mode and adjust the parameters by hand. Changing any of them switches the mode to “Custom” automatically.

Встроенных режимов хватает в большинстве случаев. Но если что-то не так — модель «ломается», текстура плывёт или остаётся слишком много полигонов — разверните «Details» под режимом уровня и правьте параметры вручную. Любое изменение автоматически переключает режим в «Custom».

Target ErrorThe “allowed error” — how far the result may differ from the original (default: a fraction of the model’s size, 0–1). Lower = stops earlier, closer to the original, but may keep more triangles than the target %. Higher = cuts harder to reach the target %, with more visible distortion. Too high (especially at a low %) can collapse the mesh entirely — if the object caves in or disappears, lower this first.«Допустимая ошибка» — насколько результат может отличаться от оригинала (по умолчанию доля размера модели, 0–1). Меньше = останавливается раньше, ближе к оригиналу, но может остаться больше треугольников, чем задано в %. Больше = режет сильнее ради целевого %, с более заметными искажениями. Слишком большое (особенно при низком %) может полностью схлопнуть меш — если объект проваливается или исчезает, сначала уменьшите его.
Pre-pruneA separate pass BEFORE main simplification (threshold 0–0.2) that strips small disconnected debris without affecting Target Error accuracy. Start at 0.01–0.05.Отдельный проход ДО основного упрощения (порог 0–0.2), срезающий мелкий несвязанный мусор без влияния на точность Target Error. Начните с 0.01–0.05.
Lock Open EdgesPrevents open/boundary edges from being touched. Keep on if the model has open edges you don’t want deformed.Не даёт трогать открытые/граничные рёбра. Держите включённым, если у модели есть открытые края, которые нельзя деформировать.
Prune (aggressive)Lets the add-on fully discard small “cheap” disconnected bits. Use when a level won’t drop to the target count due to debris.Позволяет полностью выбрасывать мелкие «дешёвые» несвязанные кусочки. Используйте, если уровень не опускается до цели из-за мусора.
↳ Limit Prune
(with Prune or Pre-prune)		Stops both prunes from deleting whole parts. Pre-prune is capped at a small share of the triangles, and if Prune still drops the result far below the requested %, Target Error is lowered and simplification is re-run. Trades hitting the triangle count for keeping the details — turn it off when Prune is meant to strip parts on a distant level.Не даёт обеим обрезкам удалять детали целиком. Предобрезке ставится потолок в виде небольшой доли треугольников, а если Prune всё равно уводит результат далеко ниже заданного %, снижается Target Error и упрощение повторяется. Обменивает попадание в число треугольников на сохранность деталей — выключайте, когда обрезка должна срезать части на дальнем уровне.
Permissive (aggressive)Lets simplification jump over texture seams if it greatly cuts polygons. For far, rough LODs; not for close-ups.Позволяет упрощению «перепрыгивать» через UV-швы, если это сильно снижает полигоны. Для дальних грубых LOD; не для крупных планов.
Protect UV Seams
(with Permissive)		Protects seams where the texture clearly differs on either side, cutting “invisible” seams freely. When Finish with Decimate is on it is forced on (a notice replaces the checkbox).Защищает швы, где текстура явно различается по сторонам, свободно срезая «невидимые» швы. При включённом Finish with Decimate принудительно включён (вместо галочки — уведомление).
↳ Protect Material Borders
(with Permissive)		The same protection, applied to vertices where the material differs across a shared position. A separate toggle from the UV seams, because there are an order of magnitude fewer material borders — protecting them costs far fewer locked vertices. Off by default in every mode: without Permissive material borders are already kept.Та же защита, но для вершин, у которых по сторонам разный материал. Отдельный переключатель от UV-швов, потому что границ материалов на порядок меньше — их защита стоит гораздо меньше запертых вершин. По умолчанию выключен во всех режимах: без Permissive границы материалов и так сохраняются.
Finish with DecimateAfter meshoptimizer runs, a Decimate (Collapse) pass reaches the exact target % when UV / material / normal seams stall it — distorts UVs less than Permissive/Sloppy, and uses the importance mask. (The Very Aggressive Alternative mode is simply this turned on as a preset.)После meshoptimizer проход Decimate (Collapse) доводит до точного целевого %, когда мешают швы UV / материалов / нормалей — искажает UV меньше, чем Permissive/Sloppy, и учитывает маску важности. (Режим Very Aggressive Alternative — это та же доводка, включённая как пресет.)
Preserve UVs & NormalsThe main “smart” toggle: tries not to ruin texture and shading. Turn off only for the farthest/roughest LODs.Главный «умный» переключатель: старается не портить текстуру и затенение. Выключайте только для самых дальних/грубых LOD.
↳ Normal Weight / UV WeightHow strongly shading and texture coordinates are protected. Normal Weight 0–1 (slider; up to 2 by typing). UV Weight 0–1 on the slider, but can be typed up to 100 to strongly pin textures. Raise Normal Weight for creases/odd highlights; raise UV Weight if the texture drifts/stretches; lower both to push polygons down on far LODs.Насколько сильно защищаются затенение и текстурные координаты. Normal Weight 0–1 (слайдер; до 2 вводом вручную). UV Weight 0–1 на слайдере, но вручную можно до 100, чтобы жёстко «прибить» текстуру. Повышайте Normal Weight при заломах/бликах; UV Weight — если текстура плывёт/тянется; понижайте оба, чтобы срезать больше полигонов на дальних LOD.
NormalsSelector — runs even with Preserve UVs & Normals off.

Preserve (from source) — carry the source normals onto the LOD. Best while simplification is moderate.
Recalculate + Smooth (experimental) — meshoptimizer generates the normals and then relaxes them, keeping edges above the angle hard. Evens out the blotchy shading an irregular triangulation leaves. Writes custom split normals, so it replaces edge marking rather than adding to it.
Recalculate + Auto Smooth — recompute from the LOD’s own geometry, marking edges sharp above Smooth Angle (Shade Smooth by Angle). Predictable at very low polycounts.
Recalculate + Sharp Loops — like Auto Smooth, but closes broken feature loops in four stages: a lower Weak angle continues a line the Strong angle started, gaps up to Bridge Length are bridged, dead-ends are trimmed, and fragments below Min Saliency are removed.

Either Recalculate mode adds a Flatten Panels toggle — it takes the normals of flat panels from their own plane, fixing flat geometry that shades as curved after the chamfer around it collapsed. Bevel Ratio sets the largest border face (as a share of the panel’s area) still counted as a chamfer: higher catches wider chamfers, lower protects rounded shapes, 0 = off.Селектор — работает даже при выключенном Preserve UVs & Normals.

Preserve (from source) — перенести нормали источника на LOD. Хорошо, пока упрощение умеренное.
Recalculate + Smooth (experimental) — meshoptimizer генерирует нормали и затем расслабляет их, оставляя рёбра круче угла жёсткими. Выравнивает пятнистое затенение от неравномерной триангуляции. Пишет кастомные split-нормали, поэтому заменяет разметку рёбер, а не дополняет её.
Recalculate + Auto Smooth — пересчитать по геометрии самого LOD, отмечая рёбра острыми выше Smooth Angle (Shade Smooth by Angle). Предсказуемо на очень низком полигонаже.
Recalculate + Sharp Loops — как Auto Smooth, но достраивает разорванные конструктивные лупы в четыре стадии: более низкий угол Weak продолжает линию, начатую углом Strong; разрывы до Bridge Length достраиваются, тупики обрезаются, фрагменты ниже Min Saliency убираются.

Любой режим Recalculate добавляет переключатель Flatten Panels — берёт нормали плоских панелей из их собственной плоскости, исправляя плоскую геометрию, которая шейдится как изогнутая после схлопывания фаски вокруг неё. Bevel Ratio задаёт наибольшую граничную грань (как долю площади панели), ещё считающуюся фаской: выше ловит более широкие фаски, ниже бережёт скругления, 0 = выкл.
↳ Vertex UpdateSlightly moves vertices and texture to fit the new shape. Better results at aggressive levels (LOD3+).Слегка двигает вершины и текстуру под новую форму. Лучше результат на агрессивных уровнях (LOD3+).
RegularizeOff / Regularize Light / Regularize — makes result triangles more uniform, at a slight cost to silhouette accuracy. Useful for meshes deformed later (rigging, sim).Off / Regularize Light / Regularize — делает треугольники результата более равномерными ценой точности силуэта. Полезно для мешей, которые потом деформируются (риг, симуляция).
Accurate Vertex ColorsBlends vertex colors along the collapse instead of keeping the surviving vertex’s color, so a painted gradient no longer comes out in steps. Slider 0–1, 0 = off. Higher values also let the color steer which edges collapse. Raising it above zero switches Vertex Update and Regularize on, since it needs both.Смешивает цвет вершин вдоль схлопывания вместо того, чтобы оставлять цвет уцелевшей вершины — закрашенный градиент больше не выходит ступеньками. Ползунок 0–1, 0 = выкл. Более высокие значения ещё и позволяют цвету влиять на выбор схлопываемых рёбер. Подъём выше нуля включает Vertex Update и Regularize, так как без них он не работает.
Importance MaskPer-vertex importance map — its source (Vertex Color / Vertex Group), strength and the hard-lock options are described in section 6.1.Карта важности по вершинам — её источник (Vertex Color / Vertex Group), сила и опции жёсткой блокировки описаны в разделе 6.1.
Voxel Remesh (experimental)Rebuilds the surface on a voxel grid instead of collapsing edges — holes close, sliver triangles go, the result is watertight; features smaller than a voxel merge. Only positions survive, so it needs Preserve UVs & Normals off. Voxel Resolution (4–256) is the grid size — higher keeps more detail and costs more (the % still applies to the result). Remesh Output: Solid (watertight outer surface, fewest tris — distant LODs / collision), Solid + Sheets (thin geometry keeps both sides — foliage, cloth, sheet metal), Shell (wraps both sides, keeps interiors, follows the original closely at ~2× tris, non-manifold).Перестраивает поверхность на воксельной сетке вместо схлопывания рёбер — дырки закрываются, тонкие треугольники убираются, результат водонепроницаемый; детали мельче вокселя сливаются. Сохраняются только позиции, поэтому нужен выключенный Preserve UVs & Normals. Voxel Resolution (4–256) — размер сетки: выше = больше деталей и дороже (% всё равно применяется к результату). Remesh Output: Solid (водонепроницаемая внешняя оболочка, меньше всего треугольников — дальние LOD / коллизия), Solid + Sheets (тонкая геометрия сохраняет обе стороны — листва, ткань, листовой металл), Shell (оборачивает обе стороны, сохраняет полости, ближе к оригиналу при ~2× треугольников, non-manifold).
Sloppy (topology-ignoring)
(last row)		A rough mode for the farthest levels: ignores topology and cuts as much as possible, replacing the normal algorithm. Lock Border, Sparse, Prune, Permissive, Regularize, weights, Vertex Update, Voxel Remesh and the Decimate finish all stop applying, and attributes are not carried at all — the panel says so in place of those rows.Грубый режим для самых дальних уровней: игнорирует топологию и режет по максимуму, заменяя обычный алгоритм. Lock Border, Sparse, Prune, Permissive, Regularize, веса, Vertex Update, Voxel Remesh и доводка Decimate перестают действовать, а атрибуты не переносятся вообще — панель сообщает об этом вместо тех строк.
